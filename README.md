# IoT-Based Landslide Early Warning System – Design Patent

## Overview
This repository documents the design registration of an **IoT-Based Landslide Early Warning System**, developed under the academic guidance of faculty at Bhagwan Parshuram Institute of Technology (BVICAM).

The prototype integrates multiple environmental and motion sensors with an ESP32 microcontroller to monitor potential landslide indicators and support real-time environmental monitoring.

## Technologies & Components

- **Microcontroller:** ESP32
- **MPU6050:** Vibration and tilt monitoring
- **BMP180:** Atmospheric pressure and altitude measurement
- **DHT11:** Temperature and humidity monitoring
- **VH400:** Soil moisture measurement
- **RG-15:** Rainfall measurement
- **ThingSpeak:** Cloud-based sensor data monitoring
- **Firmware:** Embedded C/C++ and Wi-Fi telemetry

## Key Features

- Multi-sensor environmental data acquisition.
- Real-time monitoring of rainfall, soil moisture, temperature and atmospheric conditions.
- Vibration and tilt detection.
- Wi-Fi-based telemetry and cloud monitoring.
- Threshold-based alerts for potential landslide indicators.
